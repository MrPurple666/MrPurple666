## Featured projects

### [PurpleGB](https://github.com/MrPurple666/PurpleGB)

A Game Boy emulator written in **C99 with SDL3**, built to explore how the hardware works by implementing it.

- SM83 CPU, memory bus, scanline PPU, timers, interrupts, and joypad input.
- Basic MBC1, MBC3, and MBC5 cartridge banking.
- Boots and runs some DMG ROMs, including Tetris; accuracy is still a work in progress.

**C · SDL3 · Emulation · Hardware exploration**

### [GhostDrop](https://github.com/MrPurple666/GhostDrop)

Temporary file sharing with expiration, optional passwords, and download limits.

- **Java 26** Lambda handlers with API Gateway, S3, and DynamoDB.
- Direct browser-to-S3 transfers through presigned URLs.
- React and TypeScript frontend, Terraform infrastructure, and local AWS emulation with Floci.

**Java · AWS · React · TypeScript · Terraform**

### [purple-turnip](https://github.com/MrPurple666/purple-turnip) & [freedreno-CI](https://github.com/MrPurple666/freedreno-CI)

My work around the **Mesa/Turnip graphics driver ecosystem**, including automated Android driver builds for use with Emulators.

**Graphics drivers · Android · Vulkan · Build automation**
